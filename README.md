# 🎯 Customer Churn Analytics Platform

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen)](https://ai-customer-churn-dashboard.streamlit.app/)

An AI-powered customer retention platform that predicts customer churn and provides actionable business insights through interactive dashboards and explainable machine learning.

---

## 🚀 Live Demo

https://customer-churn-analytics-dashboard-tja9vygmnmr4wznwwqmqxa.streamlit.app/

## 📌 Features

### Customer Churn Prediction

- Predicts customer churn probability using Machine Learning
- Risk classification (Low, Medium, High)
- Customer retention recommendations

### Business Analytics

- Customer distribution analysis
- Churn trend visualization
- Revenue and service insights
- Interactive dashboards

### Model Intelligence

- Feature importance analysis
- Explainable AI insights
- Model performance visualization

### Revenue Impact Analysis

- Revenue-at-risk estimation
- Retention revenue calculator
- Customer lifetime value analysis

### Reporting

- Downloadable customer reports
- Risk assessment summaries
